# Student Management System 
A simple web-based Student Management System developed using: 
- Node.js 
- Express.js 
- EJS 
- MySQL 
- Git 
- GitHub 
## Features 
- View students 
- Add students 
- Edit students 
- Delete students 
- Search students 
- Form validation 
## Installation 
Clone the repository: 
git clone (https://github.com/julascano-netizen/student-management/tree/main) 
Install dependencies: 
npm install 
Create the database. 
Configure the database connection. 
Run: 
node app.js 
Open: 
http://localhost:3000
